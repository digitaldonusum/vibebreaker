# The VibeBreaker 20/20 Challenge

## The challenge

Run the complete VibeBreaker protocol against a project you own or are authorized to audit.

A legitimate `20/20 CLEAN` result requires:

- FULL mode
- all 20 passes completed
- zero `CONFIRMED` findings after Pass 20
- zero `UNVERIFIED` findings
- no material scope limitation

Anything less should retain its actual verdict. The point is not to win the badge; the point is to make the code prove itself.

## What to share

Use the final report's share-card values:

```text
VIBE//BREAKER

VERDICT: FIX BEFORE SHIP
PASSES: 20/20
CRITICAL: 0
HIGH: 2
CONFIRMED: 5
UNVERIFIED: 1
FIRST BREAK: PASS 03 — AUTHORIZATION / IDOR
```

Suggested post copy:

> My app survived 20 VibeBreaker passes with `<verdict>`. First break: `<pass>`. 20/20 clean? Prove it. #VibeBreaker

Never publish secrets, personal data, private source code, or exploit details from software you are not authorized to disclose.
