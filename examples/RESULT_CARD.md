# Result Card Example

The final report exposes only non-sensitive summary values for sharing.

```text
VIBE//BREAKER

VERDICT: FIX BEFORE SHIP
PASSES: 20/20
CRITICAL: 0
HIGH: 2
CONFIRMED: 5
UNVERIFIED: 1
FIRST BREAK: PASS 03 — AUTHORIZATION / IDOR

NO VIBES. EVIDENCE.
```

Use `assets/result-card-template.svg` as the visual source. Replace placeholders locally; do not publish sensitive finding evidence with the card.
